Eye Detection Single Code Project
=================================

Technologies used:
- Python
- OpenCV
- NumPy
- Pandas
- Matplotlib
- Tkinter
- Flask
- SQLite
- HTML, CSS, JavaScript inside app.py

VS Code Run Steps:
1) Extract ZIP
2) Open folder in VS Code
3) Open Terminal
4) Run commands:

python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py

Open browser:
http://127.0.0.1:5000

Optional Tkinter Desktop Mode:
python app.py --desktop

Note:
Camera works best on localhost and with browser camera permission allowed.
Use clear front-face images for best eye detection.
